# Changelog

## 1.0.0

Paper mode is the default on a single PC. Real stays off until Phantom signs in the app. Public Solana RPC is the default; a private RPC can be pasted in Settings. Limits have no hard maximum. Stop pauses new buys. Jual semua still sells. The local agent listens on localhost only, starts off, and writes an audit log.

Installers: unsigned Windows NSIS and MSI, Linux AppImage and deb, and a web Docker image. No code signing. The app does not export a private key and does not send funds out of the wallet.
