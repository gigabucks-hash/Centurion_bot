# Web Interface Guidelines

This is a vendored snapshot. Do not fetch guidelines from the network.

Read [guidelines.md](guidelines.md) in this folder and check the named files against every rule in it. If no files are named, review the UI files in the current task.

Output findings in the terse `file:line` format described at the end of guidelines.md.

The upstream skill told the agent to download `command.md` from GitHub on every review, and the upstream repo also ships `install.sh`, which curls that file into home directories. Neither behavior is part of this copy.
